# PDF Export Guide - Single Page Resume

## Quick Steps

1. **Click** the blue "Download as PDF" button (top-right)
2. **In Print Dialog**:
   - Destination: **Save as PDF**
   - Layout: **Portrait**
   - Pages: **All**
   - Background graphics: **✓ Enabled**
3. **Click Save**

Your single-page professional resume is ready!

---

## Detailed Instructions by Browser

### Google Chrome / Microsoft Edge (Recommended)

1. Click "Download as PDF" button
2. Print dialog opens
3. **Destination**: Click "Change" → Select "Save as PDF"
4. **Layout**: Portrait
5. **Pages**: All
6. **More settings** (click to expand):
   - Paper size: A4 or Letter
   - Margins: Default
   - Scale: 100%
   - **Background graphics: ✓ MUST BE CHECKED** (for colors/design)
7. Click "Save"
8. Choose location and filename
9. Done! ✅

### Firefox

1. Click "Download as PDF" button
2. Print dialog opens
3. **Printer**: Select "Save to PDF"
4. **Page Setup**:
   - Orientation: Portrait
   - Scale: 100%
   - **Print backgrounds: ✓ MUST BE CHECKED**
5. Click "Save"
6. Choose location and filename
7. Done! ✅

### Safari (macOS)

1. Click "Download as PDF" button
2. Print dialog opens
3. **Bottom-left corner**: Click "PDF" dropdown
4. Select "Save as PDF"
5. **Options**:
   - Paper Size: A4 or US Letter
   - Orientation: Portrait
   - **Print backgrounds: ✓ MUST BE CHECKED**
6. Click "Save"
7. Choose location and filename
8. Done! ✅

## Ensuring Single Page Output

The resume is **automatically optimized** to fit on one page with:
- Compact spacing and margins
- Two-column layout (desktop)
- Optimized font sizes
- Efficient content organization

### Verification Steps:

1. **Before downloading**, use Print Preview (Ctrl+P / Cmd+P)
2. Check that content fits on **Page 1 of 1**
3. If you see "Page 1 of 2":
   - Ensure Scale is 100%
   - Check margins are "Default"
   - Verify paper size is A4 or Letter

## Common Issues & Solutions

### Issue 1: Colors/Design Missing

**Problem**: PDF is black and white

**Solution**: 
- ✅ Enable "Background graphics" / "Print backgrounds"
- This preserves the blue color scheme

### Issue 2: Content Spans 2 Pages

**Problem**: Resume splits across pages

**Solution**:
- Ensure Scale = 100%
- Check Paper Size = A4 or Letter
- Margins should be "Default"

### Issue 3: Text Too Small

**Problem**: Font size appears tiny

**Solution**:
- This is intentional for single-page fit
- Print settings Scale should be 100%
- Content is optimized for readability

### Issue 4: Photo Quality Poor

**Problem**: Profile photo looks pixelated

**Solution**:
- Use Chrome or Edge browser
- Ensure "Background graphics" enabled
- High-quality photo is embedded

### Issue 5: Download Button in PDF

**Problem**: PDF includes the download button

**Solution**:
- This should never happen (print:hidden CSS)
- Try refreshing page and downloading again
- Clear browser cache

## ATS Compatibility

The PDF is ATS-friendly because:

✅ **Text is selectable** - not embedded in images  
✅ **Standard fonts** - system fonts used  
✅ **Logical structure** - proper heading hierarchy  
✅ **Standard sections** - Experience, Education, Skills, etc.  
✅ **No tables** - simple layout structure  
✅ **No special characters** - standard bullets and text  
✅ **Single column flow** - easy for parsers to read  

### Test Your PDF:

1. Open the PDF
2. Try to select and copy text
3. If you can copy text → ✅ ATS will read it
4. If text is an image → ❌ Problem (shouldn't happen)
