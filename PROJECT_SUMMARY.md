
## 🎨 Design System

### Colors
```css
Primary Blue: #2563EB (Blue-600)
Background: Slate-50 to Slate-100 gradient
Text Dark: #1E293B (Slate-900)
Text Medium: #334155 (Slate-700)
Accent: #DBEAFE (Blue-100)
```

### Typography
```
Headings: System fonts (optimized for ATS)
Body: 0.7-0.85rem (print), 0.75-1rem (screen)
Line height: 1.2-1.5 (optimized for readability)
```

### Spacing
```
Compact for single-page fit
Print margins: 0.35in x 0.4in
Section spacing: 0.4rem
Mobile/desktop responsive
```
